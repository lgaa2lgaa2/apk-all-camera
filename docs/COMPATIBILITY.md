# Compatibilité caméra

La V1 lit directement les flux réseau ouverts via VLC : RTSP et HTTP vidéo, avec support potentiel MJPEG selon la forme du flux.

Familles prévues dans le catalogue : V380/V380 Pro, iCSee/iCSee Pro, Yoosee, CamHi/CamHiPro, UBox, 360Eyes/360Eyes Pro, Cam720/Cam720 Pro, Neye3C, StarEye/STAREyes, DV380, VicoHome, Cloud365, iCam/ICAM, Tuya/Smart Life, YCC365 Plus, IPC360, O-KAM Pro, CareCam Pro, XMEye/XMEye Pro, EseeCloud, Danale et génériques ONVIF/RTSP.

Une famille listée n'implique pas que son cloud propriétaire est déjà compatible. Lorsqu'un modèle ne fournit ni RTSP/ONVIF ni API/SDK exploitable, un connecteur fabricant spécifique est requis.
